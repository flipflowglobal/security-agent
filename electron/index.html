Quick Actions

System Status

Offline status and capability health

Click "Refresh Status" to load system status.

Run Built-in Tool

Execute an offline local analyzer

Select a tool and input path, then click Run.

Skills

Browse and inspect embedded skill definitions

Click "Load Skills" to see available skills.
Select a skill to view its definition.

Run External Tool

Execute a locally installed cataloged tool

Configure the tool and click Run.

Plan a Scan

Configure and plan an engagement scan

Configure the engagement and click Plan Scan.

Record Findings

Merge findings from a source log into a destination

Select source and destination, then click Record.

Schedule Retest

Generate a retest schedule from a findings log

Select a findings log, then click Schedule Retest.

Audit Log

View persisted audit records

Select an audit log file, then click View.

Audit Database

View the .sadb audit database

Select an audit database file, then click View.

Findings Database

View the .sadb findings database

Select a findings database file, then click View.

Calibration Database

View the .sadb calibration database

Select a calibration database file, then click View.

Reasoning Log Database

View the .sadb reasoning chain archive

Select a reasoning log database file, then click View.

Generate Text (LLM)

Generate text using the built-in language model

Enter a prompt and click Generate.

Anomaly Score (LLM)

Score text for anomalous content

Enter text and click Score for Anomaly.

Ask (Natural Language)

Ask a plain-English question, routed through the NLU engine

Type a question in plain English and click Ask.

About

Mission statement and roadmap

Click Load About to view mission and roadmap.

Hash Identification

Identify hash type and suggest cracking tools

Enter a hash to identify its type.

Password Strength Analysis

Analyze password entropy and crack resistance

Enter a password to analyze its strength.

Generate Wordlist

Generate a targeted wordlist for brute-force attacks

Enter a target and click Generate.

Generate Shell Payload

Select shell type and enter LHOST/LPORT.

Analyze Payload

Analyze a payload for shellcode patterns and detection risk

Enter a payload to analyze.

PowerShell Obfuscation

Enter a PowerShell command to obfuscate.

Wireless Network Audit

Audit wireless network security configuration

Configure network details and click Audit.
